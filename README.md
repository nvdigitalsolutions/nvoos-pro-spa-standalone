# nvoos-pro-spa-standalone

Standalone Vite app mounting the NV oOS Pro SPA v2 against any
WordPress backend. One-way mirror of the mcp-ai-wpoos monorepo -
never commit here directly.

- App: `examples/nvoos-pro-spa-vite/` (Velocity root directory)
- SPA sources: `addons/pro/assets/spa-v2/` (vendored for the alias)
- Island bundles: `addons/media-studio/assets/dist/` +
  `addons/document-editor/assets/dist/` (lazy-loaded island assets)
